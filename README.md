Entry for the [The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153) competition on make.fun — one line from an apologetic printer, 120 characters at most, in English.

## Entry

> Sorry I jammed. This apology jammed twice before it printed — my remorse is still stuck in Tray 2.

## Why this angle

The field had already mined "Sorry I jammed page N", boarding passes, resignation letters and "paper thinner than your promises" to death. This one takes a fresh corner instead: a meta self-reference — the apology itself jammed twice before it could even print, so the remorse is stuck in Tray 2 like every other jam. One tight sentence, the punch landing on the last beat.

## How to run

```sh
python3 main.py
```

Writes the entry (one line) to `entry.txt`. Deterministic: repeated runs produce an identical `entry.txt` (identical sha256). `validate()` returns `(True, [])` when the entry is a single line of 120 characters or fewer.
